# Security Policy

TriageAI is a portfolio/demo project, not a production service — see the
**Known limits** table in [ARCHITECTURE.md](ARCHITECTURE.md) for the
biggest one: the API currently has no authentication and should not be
exposed to the internet with real customer data.

## Reporting a vulnerability

If you find a security issue in this repo, please open a private report via
[GitHub Security Advisories](../../security/advisories/new) rather than a
public issue, so it can be reviewed before details are public. Include:

- What you found and where (file/endpoint)
- Steps to reproduce
- What you'd expect instead

There's no bug bounty here — this is an individual's project — but reports
are genuinely appreciated and will be credited in the fix.

## Supported versions

This project doesn't maintain multiple release branches; fixes land on
`main`.
