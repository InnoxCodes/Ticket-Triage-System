# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), v2.1.

In short: be respectful, assume good faith, and keep disagreements about
code, not people. Harassment, personal attacks, and discriminatory language
or behavior aren't welcome here.

Instances of unacceptable behavior can be reported by opening a GitHub issue
or contacting the maintainer directly through their GitHub profile.
